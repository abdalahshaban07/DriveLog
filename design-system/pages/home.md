# Home

Macrostructure: vehicle plate (nickname, spec, odometer) → fuel pulse (economy, spark, last fill, next due, month spend) → since-last-fill facts (days, km, estimated range) → quick log → status → month outlook → what's next → period mix → documents. The since-last-fill row is a compact receipt slip.

Primary CTA: Log fill-up only. Progressive disclosure for vehicle/recalls. Public-data L/E/E/S required.

Around / nearby POI lives on the dedicated **Around** tab (`/around`), not on Home.
